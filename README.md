# 🔐 Password Strength Checker

A simple Python project that checks the strength of a password.

## 📌 About the Project

This program checks a password based on different requirements and classifies it as Weak, Medium, or Strong.

## ✨ Features

- Checks password length
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for special characters
- Displays password strength

## 🛠️ Technologies Used

- Python

## ▶️ How to Run

1. Download or clone this repository.
2. Open `password_checker.py`.
3. Run the program using Python.
4. Enter a password when asked.
